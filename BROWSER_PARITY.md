# Browser behavior inventory

This is the working register for source-confirmed differences and missing browser
evidence. Add a row whenever an audit, capture or test discovers a difference.
Keep the browser version, primary source, implementation and remaining evidence
together. An implementation passing local tests does not establish full browser
parity. Close a row only for the explicitly recorded scope; retain capture and
platform limitations instead of silently treating them as a match.

All browser constants and cache policies belong in Surf profiles. Existing
forks expose generic protocol mechanisms only. Public cache settings are available
through `Builder.SessionCache()` and its terminal `Set()`, matching the other
Surf sub-builders. Profiles configure the same concrete fluent cache settings. Explicit application cache
choices take precedence over automatic browser-owned queues.

Go cache housekeeping is unrelated to this inventory: clear build caches only
when disk space is low. Do not delete downloaded module caches as routine cleanup.

## Header preset model

The unified model is implemented. Public SetHeaders/AddHeaders with g.MapOrd
remain the user API. Each browser's common/headers.go contains identity, defaults,
request scenarios, hint placement and protocol-specific positions. Platform
compatibility files delegate to it and hold no independent header policy.

BuildRequestHeaders returns a fresh ordered map. Its public HeaderContext contains
the request, selected OS, actual protocol, Critical-CH stage and redirect state.
Request.Fetch()/Navigation() set a concrete request kind. It is preserved through
redirects even on HTTP origins where no Fetch Metadata is emitted.
Protocol zero identifies logical defaults; the final call receives actual HTTP
major 1, 2 or 3. HeaderCase separately supplies H1 spelling, without changing
values or order. Factories never read or replace a request body.

| Step | Change and required invariant |
| --- | --- |
| 1. Logical defaults | Apply missing defaults before request middleware and refresh generated values afterward. Track explicit setters separately, even when their value equals a generated default. Keep layout metadata out of the logical request. |
| 2. User ownership | Public g.MapOrd records the user's sequence without preset sorting. Each metadata key retains independent ownership. Empty and nil explicit metadata are preserved. |
| 3. Dynamic hints | Client Hints owns origin opt-ins, cookies, body replay and restart state. It supplies values and restart context to the factory without maintaining an order snapshot. Empty declaration slots never enable unavailable hints. |
| 4. Final composition | The existing protocol-preparation boundary applies the factory on a private attempt. H3 Alt-Used is available before composition. Fallback starts again from logical headers. |
| 5. Preset declarations | Navigation, Critical-CH, redirects and fetch share one browser file. No built-in encoded method names or per-method caches remain. Blink's pure hash mechanics are separate from header declarations. |
| 6. Public compatibility | Existing standalone helpers delegate to the same factory. Custom variants without BuildRequestHeaders retain the previous callback contract. Placeholder mobile data remains explicitly labeled. |

The shared wire sorters remain responsible for physical emission. Host and
Content-Length positions are independent of their computed values. Existing
HPACK/QPACK references remain unchanged; full field-list tests also cover all
seven ordinary methods, TRACE/CONNECT, explicit order, pseudo order, body framing,
redirects, fresh/warm/Critical hints and both Surf/Std APIs. CONNECT retains the
existing TCP-only routing guard; no new HTTP/3 CONNECT API is claimed.

Native references establish the recorded H1 scenarios. H2/H3 variants in the new
method matrix exercise documented protocol deltas through real local peers;
they do not establish new native timing or scheduling parity. Current native
mobile, arbitrary renderer insertion histories and complete document context
remain separate evidence gaps.
